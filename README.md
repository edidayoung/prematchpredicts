# PrematchPredict

**AI-Powered Sports Betting Predictions** using real NBA team statistics and advanced analytics.

## Overview

This system analyzes NBA games using statistical models and real team data to find value in over/under betting markets. It combines:

- **Real Team Stats** from BallDontLie API (points, pace, defensive ratings, recent form)
- **Live Odds** from The Odds API (bookmaker lines and prices)  
- **Statistical Prediction Engine** (Four Factors approach)
- **Value Detection** (bets only when model finds edge)

## Features

✅ **Statistical Predictions** - Uses offensive/defensive ratings, pace, recent form  
✅ **Smart Value Finder** - Compares model predictions to bookmaker lines  
✅ **Automated Settlements** - Auto-checks results and tracks performance  
✅ **Performance Tracking** - Win rate, ROI, profit/loss, streaks  
✅ **Daily Pick** - One carefully selected bet per day around 2.0 odds  //
